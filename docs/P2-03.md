  "lighting":           { "tone": "warm_golden|moody_cinematic|neon|studio_clean", "key_light": "rim_light|backlight|softbox|natural" },
  "environment":        { "setting": "studio|outdoor|interior|abstract", "backdrop": "...", "atmosphere": "volumetric_fog|haze|clean" },
  "color_mood":         { "palette_hex": ["#...", "..."], "temperature": "warm|cool|neutral", "contrast": "high|low|muted", "grade": "teal_orange|desaturated|vivid" },

## 🧩 Cơ chế Prompt Pack (bắt chước `Modules/WritingStyle`)

VisualStyle dùng **cùng pattern** WritingStyle: toàn bộ câu chữ prompt nằm trong **thư mục `prompts/` riêng** (độc lập `config/config.php`), resolve qua **1 class một cửa** `VisualPromptPack`, chuyển phiên bản bằng env. KHÔNG hard-code prompt rải rác trong service/builder.

```
Modules/VisualStyle/
├── prompts/
│   ├── v1.php                # Prompt Pack V1 — đang dùng (khung key chuẩn)
│   └── presets.json          # preset shot/aspect cho UI (như WritingStyle)
├── app/Services/
│   └── VisualPromptPack.php  # resolver một cửa (resolve/pack/role/dict/limit/temperature/cap/flush + tiện ích)
└── config/config.php         # chỉ giữ setup chung + map version → key pack
```

**Khung key pack chuẩn trong `prompts/v1.php`** (giống v3.php):
```php
return [
  'pack_version' => 1,
  'extends'      => null,            // 'v1' | 'v2' | ... để deep-merge kế thừa
  'capabilities' => [                 // code rẽ nhánh theo cap(), không theo số
      'structured_analysis' => true,  // analyzer trả 5 nhóm DNA + confidence
      'seven_layer_prompt'  => true,  // builder ghép đúng 7 lớp
      'shot_overrides'      => true,  // cho phép shot ghi đè DNA
      'reference_image'     => true,  // gửi reference_media_id làm subject preservation
  ],
  'limits'        => ['max_context_chars' => 40000, 'max_output_tokens' => 4096],
  'temperatures'  => ['analyzer' => 0.2, 'prompt_builder' => 0.4, 'image' => 0.7],
  'dna_sections'  => ['composition','camera','lighting','environment','color_mood'],
  'aspect_ratios' => ['16:9','9:16','1:1','4:5'],
  'prompts'       => [                // 2 vai trò gọi AI (chuỗi system)
      'analyzer'      => "...",       // Vision: mổ xẻ ảnh → dna_json (JSON schema)
      'prompt_builder'=> "...",       // Text: ghép DNA + shot + subject → prompt sinh ảnh
  ],
  'specialties'   => [],              // overlay theo mục đích (thumbnail|hero|b_roll|portrait)
];
```

**`config/config.php`** chỉ giữ:
```php
'prompt_version' => (int) env('VISUAL_STYLE_PROMPT_VERSION', 1),
'prompt_packs'   => [1 => 'v1'],      // map số → key config nạp từ prompts/
'v1' => require __DIR__.'/../prompts/v1.php',
```

**`VisualPromptPack`** — mirror `PromptPack` (có thể tái sử dụng bằng cách cho base class chung ở `Modules/Core` sau này; giai đoạn này clone):
`resolve()`, `pack($purpose)`, `cap($name)`, `role($role,$purpose)`, `dict($name,$purpose)`, `limit($name,$default)`, `temperature($role,$default)`, `flush()` — đọc `config('visualstyle.v*')` và hỗ trợ `specialties[purpose]` overlay (thumbnail/hero/b_roll/portrait).

**DoD cơ chế:** đổi `VISUAL_STYLE_PROMPT_VERSION` = đổi pack, không sửa code; `cap()` kiểm soát rẽ nhánh; unit test `resolve` + deep-merge `extends` + overlay `specialties`.

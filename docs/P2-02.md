## Danh sách 10 Tasks Thực thi

### - [x] Task 1 — Migrations + 16 `RULE_KEYS` Seeder
- **`writing_profiles`**: `name`, `description`, `dominant_tier` enum `micro|short|medium|long` default `medium`, `rules_json` (16 keys), `evidence_json` (array `{rule_key, excerpt, note}`), `style_instructions` $\le 10000$, `origin` (`manual`/`reference`), `source_hash` char64, `analysis_metadata_json` (`word_count`, `sentence_count`, `detected_tier`, `ai_model_used`), `version`, `status` (`draft`|`active`), `is_enabled`, `created_by`.
- **`writing_profile_analyses`**: uuid PK, `name`, `source_type` (`paste`|`url`|`file`), `source_url`, `reference_text` longText, `detected_tier`, `source_hash` char64, `status` (`pending`|`running`|`succeeded`|`failed`), `ai_run_id`, `result_json`, `draft_profile_id`, `error_*`, `expires_at`.
- **Seeder 16 `RULE_KEYS` + mô tả vi mô**: (`tone`, `pronouns`, `emotion`, `opening`, `sentence_rhythm`, `paragraph_rhythm`, `transitions`, `vocabulary`, `technical_terms`, `structure_patterns`, `headings`, `bullets`, `examples`, `ending`, `avoid`, `uncertainties`).
- **Dừng**: `migrate` + `seed` xanh.

### - [x] Task 3 — `WritingProfileDefinition` + `LengthTier`
- **Const `RULE_KEYS` (16) + `LENGTH_TIERS`**: (`micro`|`short`|`medium`|`long` $\rightarrow$ sentence/word ranges theo `PLAN.md` §304: `micro` 1–3 câu $<60$ từ, `short` 4–10 câu 60–180 từ, `medium` 11–30 câu 180–600 từ, `long` $>600$ từ).
- **`detectTier(reference_text)`** — đếm câu/từ $\rightarrow$ tier.
- **`applicableKeys(tier)`** — `micro`: bỏ `headings`/`bullets`/`paragraph_rhythm` vào `uncertainties` (§304); `short` +`paragraph_rhythm`; `medium` +`opening`$\leftrightarrow$`ending`; `long` = 16/16.
- **`tierLabel(tier)`** $\rightarrow$ `'2–3 câu'`/`'3–4 câu'`/`'20–30 câu'`/`'bài dài'` (cho prompt §310).
- **Dừng**: unit test `detectTier` cho 4 mẫu + `applicableKeys` đúng theo tier.

### - [ ] Task 5 — `WritingProfileSnapshotService` (theo §310)
- **`buildSnapshot($profile, $targetTier, $targetSentences)`** $\rightarrow$ `WritingProfileSnapshotDto`:
  - Tự loại bỏ `evidence_json` (chỉ giữ `rules` + `metadata` theo tier).
  - Biên dịch `system_prompt` theo `tierLabel(targetTier)` (vd: *"viết 2–3 câu đúng khẩu khí"*).
  - Chỉ include `applicableKeys(targetTier)` — `micro` không ép `headings`/`bullets`.
- **Contract**: `WritingStyleCompilerContract`.
- **Dừng**: test snapshot KHÔNG chứa `evidence_json`, prompt chứa đúng tier label + chỉ keys theo tier.

### - [ ] Task 6 — `WritingStyleAnalyzerService` (giải mã qua `CoreAi`)
- **`analyze(reference_text, source_type, source_url?)`**:
  - `detectTier()` $\rightarrow$ `detected_tier`.
  - `CoreAi::executeStructured` với prompt *"yếu tố này trong bài mẫu là gì"* $\rightarrow$ `rules_json` (chỉ `applicableKeys(tier)`), `evidence_json` (`{rule_key, excerpt, note}`), `style_instructions`.
  - `validateEvidence()` lọc excerpt giả.
  - Tạo `WritingProfileAnalysis` (`status` = `succeeded`, `ai_run_id`, `result_json`, `source_hash` sha256, `analysis_metadata` word/sentence count + `ai_model_used`).
  - Draft `WritingProfile` (`origin` = `reference`, `draft_profile_id`).
- **Dừng**: mock `CoreAi` $\rightarrow$ assert analysis + profile có `rules`/`evidence` hợp lệ, `detected_tier` đúng.
